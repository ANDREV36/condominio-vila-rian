# Condomínio Vila Rian

Sistema web de gestão financeira do condomínio.

- Cadastro de unidades, responsáveis e valor mensal
- Caixa inicial e saldo contínuo
- Pagamentos e importação de pagamentos de 2026
- Despesas com data, descrição e valor
- Edição e exclusão de despesas pelo administrador
- Filtro por data no histórico de despesas
- Boxes recolhíveis na administração
- PostgreSQL/SQLite conforme configuração do ambiente
